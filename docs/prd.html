거래처 업무 마감 관리 도구

여러 거래처의 업무를 동시에 진행하는 사람이 거래처별 업무를 빠짐없이 기록하고, 마감시간이 가까운 순서대로 처리하도록 돕는 도구다.

  • 제품명거래처 업무 마감 관리 도구
  • 문서 상태MVP 초안
  • 제작 가능 시간2시간

1. 문서 개요

목적: 여러 거래처에서 동시에 발생하는 업무를 빠짐없이 기록하고, 마감시간이 가까운 업무부터 처리할 수 있게 한다.

2. 대상과 문제

대상

여러 거래처의 업무를 동시에 진행하며, 같은 거래처에서도 여러 업무를 함께 처리하는 사람이다.

현재 겪는 문제

  • 여러 업무를 동시에 처리해 업무가 헷갈리거나 누락되는 일이 생긴다.
  • 다이어리와 휴대폰 캘린더에 기록하고 기존 메모를 다시 확인하지만, 가끔 업무를 빠뜨린다.
  • 같은 거래처에서 서로 다른 업무가 동시에 생기면 무엇을 먼저 처리해야 하는지 판단하기 어렵다.

사용자 목표

거래처별 업무를 빠르게 기록하고 전체 미완료 업무를 마감시간순으로 확인하여, 마감이 가까운 업무부터 순서대로 처리한다.

3. MVP 핵심 기능

3.1 업무 빠른 입력

  • 첫 화면에 거래처명, 처리할 업무, 처리 마감시간 입력 칸과 추가 버튼을 표시한다.
  • 세 항목을 모두 입력하고 추가 버튼을 누르면 새로운 업무가 등록된다.
  • 같은 거래처에서도 서로 다른 업무를 각각 등록할 수 있다.
  • 입력하지 않은 항목이 있으면 업무를 추가하지 않고 해당 입력 칸에 안내 문구를 표시한다.

3.2 마감시간순 업무 목록

  • 등록된 미완료 업무는 거래처와 관계없이 마감시간이 가까운 순서대로 표시한다.
  • 각 업무에는 거래처명, 업무 내용, 마감시간, 현재 상태와 처리 버튼을 표시한다.
  • 같은 거래처의 업무는 거래처명이 같게 표시되지만 각각 독립된 업무로 관리한다.

3.3 마감 상태 표시

  • 마감까지 30분보다 많이 남은 업무는 진행 중으로 표시한다.
  • 마감 30분 전부터 해당 업무를 최대 3회 천천히 강조한 뒤, 마감 임박 문구와 강조 표시를 유지한다.
  • 마감시간이 지난 미완료 업무는 목록 최상단에 배치하고 기한 지남 문구를 표시한다.
  • 상태는 색상만으로 구분하지 않고 상태 문구를 함께 표시한다.
  • 앱을 열어 둔 상태에서만 마감 상태가 화면에 반영되며, 앱 밖으로 별도의 알림을 보내지 않는다.

3.4 업무 완료 처리

  • 실제 업무를 끝낸 사용자가 해당 업무의 처리 버튼을 누르면 상태가 처리 완료로 바뀐다.
  • 완료된 업무는 미완료 업무 아래로 이동하고 흐리게 표시한다.
  • 완료된 업무는 마감 임박 및 기한 지남 대상에서 제외한다.

3.5 자동 저장

  • 입력한 업무와 처리 상태는 현재 브라우저에 자동 저장한다.
  • 같은 브라우저에서 새로고침하거나 다시 열어도 저장한 업무와 처리 상태가 유지된다.
  • 로그인 없이 사용하는 MVP이므로 다른 기기나 다른 브라우저와 자료를 공유하지 않는다.

4. 사용자 흐름

  1. 사용자는 첫 화면에서 거래처명, 처리할 업무, 처리 마감시간 입력 칸과 추가 버튼을 본다.
  2. 세 항목을 입력하고 추가 버튼을 누르면 업무가 마감시간순 목록에 표시된다.
  3. 같은 거래처에서 다른 업무가 생기면 거래처명과 새로운 업무 및 마감시간을 같은 방식으로 추가한다.
  4. 사용자는 목록 상단의 기한 지남 또는 마감 임박 업무부터 실제로 처리한다.
  5. 실제 업무를 끝낸 뒤 해당 업무의 처리 버튼을 누르고, 업무가 목록 아래의 처리 완료 상태로 이동한 것을 확인한다.

5. 화면 구성

상단: 업무 입력 영역

  • 거래처명 입력 칸
  • 처리할 업무 입력 칸
  • 처리 마감시간 입력 칸
  • 추가 버튼

하단: 전체 업무 목록

  • 기한 지남
    마감시간이 지난 미완료 업무
  • 마감 임박
    마감까지 30분 이하로 남은 미완료 업무
  • 진행 중
    마감까지 30분보다 많이 남은 미완료 업무
  • 처리 완료
    사용자가 처리 버튼을 누른 업무

미완료 업무는 기한 지남을 가장 위에 표시하고, 나머지는 마감시간이 가까운 순서로 표시하며, 완료 업무는 목록 가장 아래에 표시한다.

6. 데이터 항목

업무 한 건은 거래처명, 처리할 업무, 처리 마감시간, 현재 상태, 등록 시각과 완료 시각을 가진다.

7. 완료 기준

  • 여러 거래처의 업무를 각각 등록할 수 있다.
  • 같은 거래처의 업무를 여러 개 등록할 수 있다.
  • 거래처명, 업무 내용 또는 마감시간이 비어 있으면 등록되지 않는다.
  • 미완료 업무가 정해진 우선순위와 마감시간순으로 표시된다.
  • 마감 30분 전 업무에 마감 임박 문구가 표시된다.
  • 마감시간이 지난 미완료 업무에 기한 지남 문구가 표시된다.
  • 처리 버튼을 누른 해당 업무만 처리 완료로 바뀌고 목록 아래로 이동한다.
  • 새로고침하거나 같은 브라우저를 다시 열어도 업무와 처리 상태가 유지된다.

8. 이번 MVP에서 제외할 것

  • 프로젝트 단계 및 프로젝트별 묶음
  • 거래처 전체 완료와 프로젝트 자동 완료
  • 업무 수정 및 삭제
  • 업무 순서 수동 변경
  • 업무별 추가 메모
  • 다이어리 내용 일괄 입력
  • 휴대폰 캘린더 연결
  • 앱을 닫았을 때 보내는 푸시 알림
  • 여러 기기 간 자료 동기화
  • 로그인과 결제

9. 추후 계획

우선 검토

  • 잘못 입력한 업무의 수정 및 삭제
  • 완료 업무만 모아 보거나 숨기는 기능
  • 사용자가 마감 임박 기준시간을 직접 정하는 기능
  • 거래처명을 다시 입력하지 않고 기존 거래처를 선택하는 기능

다음 단계

  • 거래처 아래에 프로젝트를 만들고 프로젝트별로 업무를 구분하는 기능
  • 업무별 추가 메모 및 업무 순서 수동 변경
  • 다이어리 내용을 한꺼번에 입력해 여러 업무로 등록하는 기능
  • 휴대폰 캘린더 연결 및 앱을 닫았을 때 보내는 알림
  • 로그인과 여러 기기 간 자료 동기화

10. MVP 원칙

  • 거래처는 업무를 구분하기 위한 정보로 사용한다.
  • 첫 화면의 중심은 거래처별 화면이 아니라 전체 마감시간순 업무 목록으로 한다.
  • 실제로 처리해야 하는 업무 한 건을 완료의 최소 단위로 삼는다.
  • 2시간 안에 핵심 흐름이 작동하도록 디자인 완성도보다 입력, 정렬, 상태 표시, 완료 처리와 저장을 우선한다.
